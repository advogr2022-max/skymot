# Skymot APK 1.4.1 — чеклист обновления для заказчика

Дата: 10.08.2026
Версия APK: **1.4.1** (пакет `skymot.winch`, versionCode 141)
Что это: обновление приложения управления лебёдкой (линия регресса от проверенной v1.1.0 + новые функции)

---

## 1. Зачем (кратко)

Версии 1.3.0/1.3.1 показали нестабильность при подключении к контроллеру. Поэтому v1.4.0 построена **заново от рабочей v1.1.0** (проверенное поведение кнопок и связи BLE), поверх которой добавлены: **модуль авто-смотки VeryFastRewind** (независимая работа от прошивки), **файловые логи** (видимы в файловом менеджере — инженер может прислать с поля), **версия на экране коннекта**. Прошивка VESC **не изменялась**.

## 2. Что именно сделано (чеклист изменений)

| # | Что изменено | Детали |
|---|---|---|
| 1 | **Модуль авто-смотки VeryFastRewind** | Когда контроллер входит в режим REWINDING, APK сам управляет мотором: эмуляция кнопки FAST (заданные ERPM) каждые 50 мс до зоны 25 м от нуля, затем SLOW (медленные ERPM) до нуля. Плавный разгон (Ramp time), защита по току, кнопка Stop останавливает. Включается/выключается переключателем в настройках |
| 2 | **Блок настроек «Fast rewind»** | На экране настроек: 7 параметров авто-смотки (скорость быстрой/медленной фазы, макс. токи, зона переключения 25 м, время разгона). Хранятся на смартфоне, на контроллер не отправляются |
| 3 | **Версия на экране коннекта** | Заголовок «Find Skymot 1.4.1» — версия из бинарника, видно сразу, какая сборка установлена |
| 4 | **Файловые логи** | Все сообщения приложения пишутся в `Загрузки/Skymot/*.log`, посекундные записи смотки — в `*smot.log`. **Видимы в файловом менеджере** (MediaStore) — инженер с поля отправляет файл как вложение |
| 5 | **Исправление краша при запуске** | Добавлены недостающие разрешения Android (ACCESS_NETWORK_STATE и др.) — без них приложение падало при старте |
| 6 | **Кнопка Stop активна при смотке** | Во время REWINDING/SLOWING/SLOW кнопка Stop доступна и останавливает мотор |

## 3. Как обновить

1. Скачать APK: https://github.com/advogr2022-max/skymot/releases/tag/v1.4.1
2. Установить поверх старой версии (настройки сохранятся). Если была 1.3.x — рекомендуется сброс: Настройки Android → Приложения → Skymot → Очистить данные (настройки смотаются заново, дефолты пропишутся сами)
3. Запустить, на экране коннекта убедиться, что заголовок «Find Skymot 1.4.1»
4. Включить контроллер ДО запуска приложения

## 4. Проверка на земле (без пилота)

| Тест | Ожидание |
|---|---|
| Запуск приложения | Заголовок «Find Skymot 1.4.1», нет краша, в `Загрузки/Skymot/` появились файлы `.log` |
| Подключение к контроллеру по BLE | Статус меняется с Disconnected на штатный (No Valid Settings → Braking после настройки) |
| Кнопки FAST/SLOW | Работают как в v1.1.0 (проверенное поведение) |
| Авто-смотка | При статусе Rewinding строка статуса на приборе показывает **«VeryFastRewind» оранжевым** — работает наш алгоритм. Трос сматывается быстро до ~25 м, затем медленно до нуля, мотор останавливается |
| Кнопка Stop при смотке | Останавливает мотор, статус → Manual Braking |
| Логи | После теста открыть `Загрузки/Skymot/` — файлы логов, отправить инженеру при проблемах |

## 5. Настройки авто-смотки (экран настроек → Fast rewind)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| Fast rewind | Вкл | Включает модуль авто-смотки |
| Rewind speed (ERPM) | 20000 | Скорость быстрой фазы (до 25 м) |
| Rewind max current (A) | 150 | Защита по току быстрой фазы |
| Rewind slow speed (ERPM) | 2000 | Скорость медленной фазы (ближе 25 м) |
| Rewind slow max current (A) | 25 | Защита по току медленной фазы |
| Rewind slow zone (meters) | 25 | Зона переключения FAST→SLOW (ближе — только SLOW) |
| Ramp time (secs) | 1.0 | Время плавного разгона/торможения |

## 6. Что НЕ менялось

- Прошивка VESC — **не изменялась** (все доработки только в APK)
- Поведение кнопок FAST/SLOW и BLE-связь — как в проверенной v1.1.0
- Пакет `skymot.winch`, minSdk 26, targetSdk 34

## 7. Если что-то не так

- Приложите лог из `Загрузки/Skymot/` (последний `*.log` и `*smot.log`) — по нему видно всю работу приложения
- При краше подключения: logcat (`adb logcat -d`) + файловый лог
