# Skymot 1.3.1 — Fast Rewind + файловые логи

## Что нового в 1.3.1

### 1. Файловые логи (Download/Skymot/)

Программа пишет полный лог работы в доступное файлменеджерам место:

```
Загрузки/Skymot/20260810_1357.log        — общий лог (старт, состояния, QML-ошибки, краши)
Загрузки/Skymot/20260810_1357smot.log    — лог смотки (посекундно)
```

- **Общий лог**: каждое событие с временем (`2026-08-10 13:57:01.234 W ...`) — по нему видно всю работу приложения и точную причину падения
- **Лог смотки** `...smot.log`: маркеры начала/конца смотки и посекундные записи:
  ```
  === REWINDING START ===
  13:57:05 REWINDING pos=312.5м I=45.2А erpm=15600
  13:57:06 REWINDING pos=298.1м I=44.8А erpm=15480
  ...
  === REWINDING END -> SLOWING
  ```
  — ток мотора, ERPM и расстояние конца троса до нуля каждую секунду
- Если папка Загрузки недоступна — лог пишется в `Android/data/skymot.winch/files/` (видно через USB/менеджер файлов)

### 2. Исправления (важно)

- **Устранены две QML↔C++ ошибки** в алгоритме Fast Rewind:
  - `Skypuff.pos` (несуществующее свойство) → `Skypuff.drawnMeters` (реальные вытянутые метры)
  - `Skypuff.setStatus(msg, true)` (закрытый метод) → новый публичный `Skypuff.postStatus(msg, warning)`
- **Таймер Fast Rewind вооружается через 10 сек после подключения** к контроллеру (не вмешивается в обмен конфигом сразу после BLE-коннекта)
- **Настройки Fast Rewind** — как в 1.3.0 (Switch + 6 параметров, QSettings смартфона)

### 3. Напоминание из 1.3.0 (Fast Rewind)

- Быстрая смотка в автоматике: пока BLE на связи, обход штатного алгоритма (быстрая фаза → плавное торможение → медленная зона 25 м)
- Кнопки FAST/SLOW с плавным разгоном, индикатор в центре прибора (серый/красный)
- Кнопка Stop активна в смотке
- Защита от зацепа (2 сек → медленная, +5 сек → стоп)

## Перед полевыми испытаниями (важно!)

1. **Motor poles = 6** — проверь в настройках APK (VESC drive settings). ⚠️ При отправке настроек APK перезаписывает motor_poles контроллера (дефолт UI = 32!)
2. **l_max_erpm** в VESC Tool — если 15600, подними до ~45000 для скорости смотки до 40 м/с
3. **l_current_max = 170А** — потолок, Fast Rewind работает до 150А с запасом

## Если приложение упадёт

Пришли файлы из `Загрузки/Skymot/` (или `Android/data/skymot.winch/files/`) — по логу сразу видно причину.

## Установка

- Установите `Skymot-1.3.1.apk` поверх 1.3.0 (настройки сохранятся)
- Откат: `Skymot-1.1.0.apk` (релиз v1.1.0)
